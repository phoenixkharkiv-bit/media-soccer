# Архив Чемпионата АЖИ по футзалу

Статический сайт без сервера и базы данных. Все данные лежат в папке `data` в обычных файлах JSON, а страницы собираются в браузере из этих файлов. Поэтому сайт можно разместить на любом статическом хостинге: GitHub Pages, Netlify, Cloudflare Pages.

## Как устроен проект

```
index.html            главная страница сайта
assets/core.js        расчёты: таблицы по регламенту, карточки команд и игроков, рекорды
assets/stats.js       статистика с фильтрами: игроки, команды, сравнение, матчи, серии, стандарты, дисциплина, судьи
assets/charts.js      графики (SVG, без внешних библиотек)
assets/app.js         страницы сайта
assets/style.css      оформление
data/seasons.json     список сезонов по порядку
data/seasons/*.json   по файлу на сезон: турниры и матчи
data/teams.json       команды и все их названия
data/players.json     склейка разных написаний игроков и разделение тёзок
data/reviews/*.json   обзоры и анонсы туров по сезонам, с авторами
tools/blogger_import  скрипты, которыми данные перенесены из блога
```

## Как открыть сайт у себя

Из папки проекта запустите `python3 -m http.server` и откройте в браузере `http://localhost:8000`. Если открыть `index.html` двойным щелчком, данные не загрузятся: браузер не разрешает читать файлы с диска.

## Файл сезона

Каждый матч занимает одну строку:

```json
{"id":"2021-22-chemp-001","t":"chemp","div":null,"stage":"1 тур","date":"2021-09-04",
 "home":"Слобода","away":"Спартак","score":[2,7],"ref":"Емец Богдан","venue":"Спорткомплекс НФаУ",
 "goals":[["Гапочка Сергей",23,"a"],["Артюшенко Антон",41,"h"]],
 "lineups":{"h":[[7,"Артюшенко Антон"]],"a":[[null,"Аболымов Михаил"]]},
 "yc":[["Горелков Николай","h",33]],"rc":[],"stats":{"shots":[20,26]}}
```

Что означают поля:

- `t` — турнир сезона: `chemp` — чемпионат в сезонах с одной лигой, `media` — Медиа-лига, `brand` — Бренд-лига, `cup` — Кубок АЖИ, `gold` — «Золотая середина», `hope` — Кубок Надежды, `cl` — Лига Чемпионов, `lc` — Кубок Лиги. Список турниров сезона задан в начале файла в `tournaments`.
- `div` — лига («Медиа-лига», «Бренд-лига») или группа кубка («Группа A»); `null`, если деления нет.
- `stage` — «N тур» для кругового этапа или «1/4 финала», «1/2 финала», «За 3-е место», «За 5-8 места», «Финал».
- `score` — счёт `[хозяева, гости]`. Серия пенальти: `"pens":[3,2]`. Техническое поражение без счёта: `"tech":["+","-"]`; технический результат со счётом 6:0 помечается `"tech":true`.
- `goals` — `[игрок, минута, сторона]`, где сторона `h` — хозяева, `a` — гости, то есть команда, которой засчитан гол. Четвёртый элемент: `"og"` — автогол, `"pen"` — пенальти, `"tenm"` — 10-метровый штрафной, `"free"` — штрафной удар. Если 10-метровых в сезоне нет, блок о них на сайте не показывается.
- `lineups` — составы `[номер, игрок]`; номер может быть `null`.
- `yc`, `rc` — предупреждения и удаления `[игрок, сторона, минута]`.
- `mp` — незабитые пенальти и штрафные `[игрок, сторона, минута, исход]`, исход: «вратарь», «мимо», «штанга».
- `stats` — `shots` (удары), `on_target` (в створ), `woodwork` (штанги и перекладины), `corners` (угловые), `fouls` (фолы), каждое `[хозяева, гости]`.

Имена игроков пишутся так же, как в протоколах: «Фамилия Имя».

## Как добавить новый турнир или матч

1. Откройте файл сезона, например `data/seasons/2026-27.json`. Новый сезон: скопируйте структуру любого файла и добавьте его id в `data/seasons.json`.
2. Добавьте турнир в `tournaments`, если его ещё нет.
3. Добавьте строку матча в `matches`. Таблицы, бомбардиры, рекорды и карточки команд и игроков пересчитаются сами.

## Команды, переименования и клубы

В `data/teams.json` у каждой команды есть список `names`. Все названия из списка считаются одной командой, и на её странице видна история: под каким названием она играла в каком сезоне. Чтобы связать переименованную команду, перенесите старое название в `names` основной карточки, а пустую карточку удалите.

Если у клуба было несколько составов (например, по одному в медиа- и бренд-лиге), каждый состав остаётся отдельной командой со своей статистикой, а поле `"club": "АЖИ"` связывает их. На странице состава показаны ссылки на другие составы клуба.

## Игроки

Игрок определяется по написанию имени без учёта регистра и разницы «е/ё». Если один человек записан по-разному, добавьте пару в `data/players.json`:

```json
{"merge": [["Мелихов Иван", "Мелехов Иван"]], "split": []}
```

Первым идёт основное написание. Если двое разных людей записаны одинаково, их разделяют по команде или по матчам:

```json
{"split": [
  {"name": "Коваленко Александр", "teams": ["Наша команда"], "as": "Коваленко Александр (Наша команда)"},
  {"name": "Иванов Сергей", "match_ids": ["2015-16-brand-014"], "as": "Иванов Сергей (2)"}
]}
```

## Обзоры

Файлы `data/reviews/<сезон>.json` содержат тексты обзоров по абзацам и автора. Если автор неизвестен, поле `author` равно `null`, и на сайте написано «автор не указан». Список всех обзоров для страниц сезонов лежит в `data/reviews/index.json`; при добавлении обзора его нужно внести и туда.

## Статус турнира

Сайт сам определяет, завершён ли круговой турнир: сыгран ли последний тур полного числа кругов. Если это нужно задать вручную, добавьте турниру в `tournaments` поле `"status": "finished"`, `"unfinished"` или `"unknown"` и при желании `"note"` с пояснением.

## Размещение на своём домене (GitHub Pages)

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В настройках репозитория откройте Pages и выберите ветку `main`, папку `/ (root)`.
3. В поле Custom domain укажите `www.media-soccer.org`, а у регистратора домена поменяйте записи DNS по инструкции GitHub. Старый блог останется доступен по адресу на blogspot.com.
4. Второго администратора добавьте в репозиторий как соавтора (Settings → Collaborators). Каждое изменение сохраняется в истории с именем автора, и его можно откатить.
