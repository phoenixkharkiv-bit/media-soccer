# Чтение файлов программы «Футбольные чемпионаты» (.fbl)

`python3 fbl.py турнир.fbl` выводит название турнира, команды и сколько прочитано матчей, голов, игроков и составов.

Формат восстановлен по файлу «Чемпионат АЖИ 2015/16, бренд-лига» и сверен с протоколами блога. Из файла читаются:
- команды;
- матчи: дата, тур, зрители, счёт, статистика (угловые, фолы, удары, удары в створ, штанги);
- голы с автором и минутой;
- игроки с номерами;
- составы с сыгранными минутами и предупреждениями.

В записях игроков есть даты рождения. На сайт они не переносятся.
