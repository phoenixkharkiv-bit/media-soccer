# Перенос данных из выгрузки Blogger

Скрипты, которыми архив собран из резервной копии блога media-soccer.org (feed.atom).

1. `parse.py feed.atom posts.json` — посты и страницы из выгрузки.
2. Подготовка строк: функция `lines()` из `h2t.py` превращает HTML поста в строки (см. начало `parse_matches.py`, вход — `lines.json`: `[{"d": дата, "t": заголовок, "L": [строки]}]`).
3. `parse_matches.py lines.json m.json m.log` — разбор протоколов матчей.
4. `build_data.py <папка с m.json и past_lines.json> <папка проекта>` — нормализованные файлы `data/`. В начале скрипта перечислены ручные исправления (`FIXES`) и статусы турниров (`STATUS`).
5. `validate.js <папка проекта> <папка с published_tables.json>` — сверка рассчитанных таблиц с опубликованными в блоге.

Повторный запуск перезаписывает `data/`, поэтому правки, внесённые в данные вручную после импорта, при этом потеряются.
