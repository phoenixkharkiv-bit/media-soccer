# Архив Чемпионата АЖИ по футзалу (media-soccer.org)

Сайт-архив журналистского турнира по футзалу в Харькове, сезоны 2003–2022. Владелец и главный администратор — Алексей. Отвечай по-русски, простыми словами: Алексей не программист.

## Как устроен сайт

Статический сайт без сервера и сборки: `index.html`, скрипты в `assets/`, данные в `data/` (JSON). Публикуется через GitHub Pages из ветки `main`, папка `/`. Домен www.media-soccer.org. Подробное описание форматов данных — в `README.md`, читай его перед правкой данных.

- `assets/core.js` — таблицы по регламенту, команды, игроки, рекорды
- `assets/stats.js` — расчёты для раздела «Статистика»
- `assets/charts.js` — графики (свой SVG, без библиотек)
- `assets/app.js` — страницы сайта
- `data/seasons/*.json` — матчи по сезонам, `data/teams.json` — команды и их названия, `data/players.json` — склейка написаний и тёзки, `data/reviews/` — обзоры

## Порядок работы

1. Перед правкой убедись, что локальная копия свежая (`git pull`).
2. После правки покажи результат локально: `python3 -m http.server 8000` в корне проекта и ссылка http://localhost:8000. Открывать `index.html` двойным щелчком нельзя, данные не загрузятся.
3. Коммить и отправляй на GitHub (`git push`) только когда Алексей прямо скажет «опубликуй» или «сохрани». Сообщение коммита — коротко, по-русски или по-украински, что изменилось.
4. Если что-то сломалось после публикации — предложи откатить последний коммит.

## Правила по данным

- Никогда не выдумывай данные, счёт, авторов, игроков. Если чего-то нет в протоколе — спроси.
- Даты рождения игроков из файлов программы «Футбольные чемпионаты» (.fbl) используются только чтобы различать тёзок. На сайт их не выводить.
- Переименования команд определяются по костяку состава, но каждое переименование подтверждает Алексей.
- Бренд-лига и Медиа-лига — разные по уровню лиги. У клуба могут быть два состава, по одному в каждой лиге, связанные полем `club`; некоторые игроки играют в обоих.
- Турниры называть полностью: Медиа-лига, Бренд-лига, Кубок АЖИ, Кубок «Золотая середина», Кубок Надежды, Лига Чемпионов, Кубок Лиги.
- Технические результаты оставлять как в блоге (0:6).
- Сезон 2019/20 — один круг, завершён. Сезон 2021/22 не доигран: после 18 тура (19 февраля 2022 г.) началась война.
- Сторонние турниры (Elite, пляжный футбол) на сайт не добавлять.
- Стандарты: пенальти (`pen`), 10-метровый штрафной (`tenm`), штрафной удар (`free`) — три разных вида, статистика по ним отдельная.
- Скрипты в `tools/` — для импорта из блога и из .fbl. Не перезапускай `tools/blogger_import/build_data.py` без согласования: он перезапишет `data/`, и ручные правки пропадут.
